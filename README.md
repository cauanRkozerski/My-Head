# My-Head 🌀

Repositório da atividade prática de **GitFlow, Pull Request e Deploy no GitHub Pages**, utilizando como base a animação *head-spinning* desenvolvida com **GSAP** e **Bootstrap 5**.

🔗 **Página Publicada no GitHub Pages:** [https://cauanrkozerski.github.io/My-Head/](https://cauanrkozerski.github.io/My-Head/)

---

## 📌 Sobre o Projeto
Este repositório foi criado para exercitar as boas práticas de engenharia de software e versionamento colaborativo:
- Estruturação de branches utilizando o modelo **GitFlow** (`main`, `develop`, `feature/*`).
- Criação e integração de **Pull Requests** com descrição e checklist padronizados.
- Configuração e deploy automatizado através do **GitHub Pages**.
- Personalização visual e interativa do projeto de aula *head-spinning*.

---

## 🌳 Estrutura do GitFlow

```text
main (produção / GitHub Pages)
 │
 └── develop (integração)
      │
      └── feature/integrar-head-spinning (desenvolvimento da página e animação GSAP)
```

---

## 🛠️ Tecnologias Utilizadas
- **HTML5 & CSS3** (Estrutura semântica e estilização moderna responsiva)
- **JavaScript (ES6+)**
- **GSAP 3 (GreenSock Animation Platform)** (Animação contínua da cabeça giratória e controles de velocidade/pausa)
- **Bootstrap 5** (Grid e componentes utilitários)
- **Git & GitHub** (Controle de versão e Pull Requests)
- **GitHub Pages** (Hospedagem estática contínua)

---

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/cauanRkozerski/My-Head.git
```

2. Acesse a pasta do projeto:
```bash
cd My-Head
```

3. Abra o arquivo `index.html` em seu navegador ou utilize a extensão **Live Server** no VS Code / IDE.
