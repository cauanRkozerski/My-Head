Projeto prático integrando a animação head-spinning da aula com o fluxo GitFlow e deploy no GitHub Pages.

🎓 Sobre o Projeto My-Head

Este projeto foi desenvolvido como atividade prática universitária para aplicação do modelo de ramificação GitFlow, criação de Pull Requests estruturados com template e publicação contínua através do GitHub Pages.

Utilizamos como base o projeto head-spinning desenvolvido na aula anterior com GSAP (GreenSock), personalizando o layout e integrando novos recursos interativos.

🌿 Fluxo GitFlow Aplicado

  • Branch main: Versão estável em produção publicada via GitHub Pages.
  • Branch develop: Ambiente de integração de novas funcionalidades.
  • Branches feature/*: Desenvolvimento isolado de recursos (ex: animação, estilos e componentes).
  • Pull Requests Padronizados: Revisão com checklist e template documentado.
